# qwRogue

[![License](https://img.shields.io/badge/license-BSD-blue.svg)](LICENSE.TXT)

**qwRogue** stands for "**qwembus Rogue**" and is a console roguelike game by me, qwembus, forked from [David Silva's **Rogue 5.4.4** preservation of the original game's *v5.4* source code](https://github.com/Davidslv/rogue). The original game was developed by, at various points in time over different versions, Michael Toy, Ken Arnold, and Glenn Wichman (1980-1983, 1985, 1999).

As things stand now, the main branch of this repository holds just that source code with no changes, but I'm working on developing it into a proper fork and eventually a proper new game in its own right, with the following changes and additions (for starters):

**Quality of life stuff** 

* colours
* better aesthetics for the ascii, not limited to just the aforementioned colours but also different symbol selection in some cases
* wielding/unwielding weapons, wearing/taking off armor, and putting on/taking off rings all to be bundled into a new command, "E," which will basically just copy the [**DCSS**](https://crawl.develz.org/) equipment menu
* replace/revamp the "/" command with an equivalent to **DCSS*' "x" and "v" commands to get information about what's actually on screen vs. the meaning of the symbol in general

_(More to come)_
